# yuriRico

Site da yuriRico com apresentação dos serviços, três protótipos interativos e formulário de orçamento integrado ao WhatsApp.

## Publicação

GitHub Pages publica a raiz da branch `main`:

https://yurilingua.github.io/yuriRico/

Site estático em HTML, CSS e JavaScript, sem etapa de build. Edite os arquivos e envie as mudanças à branch `main` para atualizar a publicação.

## Estrutura

- `index.html`: página principal e formulário.
- `style.css`: layout responsivo.
- `app.js`: filtros, protótipos e abertura do WhatsApp com os dados preenchidos.
- `demos/`: três sites fictícios de demonstração.
- `.nojekyll`: preserva a publicação dos arquivos estáticos.

## Contato e personalização

O formulário abre `https://wa.me/5571991334337` com a mensagem preparada; o cliente confirma o envio no WhatsApp.

O espaço à esquerda da apresentação está reservado para a foto de Yuri. Os protótipos são fictícios. Imagens e fontes são carregadas de Unsplash e Google Fonts.
